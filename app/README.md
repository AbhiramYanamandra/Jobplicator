# FastAPI backend

Start from the source repository: `./app/run.sh` (macOS/Linux) or `app\run.bat` (Windows).

The launcher builds React, migrates the configured development database and starts FastAPI. For hosted deployment and data migration, follow [the root README](../README.md) and [DEPLOYMENT.md](../DEPLOYMENT.md). Python 3.13 and Node.js 24 LTS are required for the source workflow.
